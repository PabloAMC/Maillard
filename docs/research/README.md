## How To Read These Documents

Use these notes when you need one of the following:

- scientific justification for a mechanism, parameter, or target family
- product planning context for future benchmark expansion
- literature support behind a matrix assumption or chemistry choice

If you only need to use the tool, go back to [../guides/QUICKSTART.md](../guides/QUICKSTART.md).
