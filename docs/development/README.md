## How To Use This Material

- Read `tasks/todo.md` to understand current priorities.
- Read `tasks/lessons.md` to avoid repeating prior process mistakes.
- Read `docs/dev_logs/` when you need the rationale behind a design choice or calibration decision.

## Why This Exists

These documents are important, but they should not be mixed into the main onboarding path for scientists who only need to understand what the tool does, how to run it, and how much to trust it.
