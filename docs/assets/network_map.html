The network itself, all four lanes

Unweighted: every step drawn at the same width, so this is the model's STRUCTURE rather than any one process's chemistry. The lanes do not compose — the sulfur steps are deliberately absent from the acrylamide lane, because composing them would spend the same cysteine twice.

A node with NO edges in a lane is a state variable that lane carries but never touches. The acrylamide lane is the clear case: it shares the sulfur lane's whole state vector while omitting every sulfur STEP, so every sulfur species appears there as an isolated node. That is the refusal to compose, drawn.
