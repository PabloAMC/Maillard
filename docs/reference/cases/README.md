# Change cases

A case is the one-page record a W2 chemistry step carries in its PR, written under [STATUS_AND_PLAN sec. 7](../../guides/STATUS_AND_PLAN.md).
Items 1 - 5 (claim, evidence by kind, rivals, decisive data, tolerances) are written before any result of the change exists.
Items 6 - 9 (comparison, side effects on the held-out benchmark, adversarial review, decision) are appended after, never edited into 1 - 5.
Each case also says which held-out results its author had already seen, and what the build must still decide.
Files are named after the plan step (`M1_...`, `M1b_...`); the decision goes into `docs/reference/experiment_register.yml` as an EX entry.
