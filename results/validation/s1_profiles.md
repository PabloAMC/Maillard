# S1 profile likelihoods

_Generated by `scripts/generators/build_s1_profiles.py`; the rule: plan sec. 7 S1 and `src/evidence_tiers.py`. Identification only, never credit (the fits' own rows). Changes no tier: an upgrade needs this artifact and a second reader, entered in `docs/reference/evidence_tier_changes.yml`._

## Method

For each coordinate, on the fit that froze its shipped value and that fit's own residual function, rows, sigmas, free set and search bounds: a full re-fit from the frozen point (the engine's fit driver, `src.kinetic_core.fitting.fit`, with a central-difference polish), then a walk outward on both sides (first step = the Laplace 95 % half-width / 2.5, growing) re-optimising every OTHER free coordinate of the fit at each grid value, warm-started from the neighbouring point, until the profile rises past the largest threshold (one point beyond) or reaches the search bound. S_min is the lowest S seen (the refit or any profile point). JAX was not used: none of these fits' objectives is a `JaxProblem`.

Calibration: likelihood ratio, Delta = S_p(psi) - S_min with S = r . r. raw: Delta <= chi2_1(0.95) = 3.841 (Wilks, the rows' stated sigmas). scaled (the verdict): Delta / max(1, chi2_red) <= 3.841, the residual variance inflated by the fit's reduced chi-square when above one, as each fit's own Laplace covariance does. F: Delta / chi2_red <= F(0.95; 1, dof), reported when chi2_red > 1 as a small-sample check. Edges by signed-root interpolation. Asymptotic (regular interior optimum, Gaussian residuals); not checked by simulation.

Judgement: meets the profile requirement = the scaled interval closes on BOTH sides by the likelihood strictly inside the search bounds (a search bound never closes it: S4), the refit and every profile point inside the interval converged (the optimiser stopped on a tolerance and the central polish was not exhausted; a polish that raised the cost carries the forward endpoint, as fitting.fit does, and is listed; a non-converged point is retried once with twice the polish) with no failed pot, the SHIPPED value inside the interval (where the engine changed under the fit's rows since it froze, today's optimum can sit elsewhere: S1's 're-derived for the coordinates whose rows a structural change moves'), and the interval inside a measured or class band where one is on record (none of the 28 has one: their bands are the fit's own Laplace sigma, the search bounds, a fixed value or nothing; containment is then undefined and the closure is the likelihood's alone). Sulfur-lane and pH-drift coordinates: conditional on B0 (falsified under S3: PR #94, M1b part (i), amendment A2); no upgrade proposed. A coordinate that meets the requirement is PROPOSED as an upgrade only when it is not conditional, the S1 record flags none of its fit's rows as withdrawn or corrected (a profile on contested rows pins the coordinate to them, not to the chemistry), and today's engine reproduces the fit's frozen objective (else the fit needs re-deriving before any tier moves).
